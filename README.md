# SCIC 월간 소식

사랑의교회 SCIC 동문회의 월간 소식지 보관함입니다. 소식은 두 가지로 나눕니다.

- 전체 행사 소식
- 선교 그룹 소식 (처음엔 13개, 편집실이나 선교 그룹 화면의 '+ 새 그룹'으로 더 만듦)

소식마다 육하원칙(누가·언제·어디서·무엇을·어떻게·왜), 본문, 사진, 영상, 인터뷰를 담습니다. 연도와 달로 모아 보고, 카카오톡과 이메일로 보낼 수 있습니다.

## 쓰는 법

- 읽기: 누구나 주소만 있으면 봅니다. 로그인이 없습니다.
- 쓰기: 주소 끝에 `#/admin`을 붙여 편집실에 들어가 구글로 로그인합니다. Firestore `meta/editors` 문서({admins, editors})에 이메일이 있는 사람만 쓸 수 있습니다. 관리자는 편집실 '편집자 관리'에서 명단을 고칩니다.
- 카카오톡 안에서는 구글 로그인이 막히므로 다른 브라우저로 엽니다.
- 체험: 주소 끝에 `?demo`를 붙이면 그 기기에만 저장하는 체험 모드가 됩니다. '구글로 로그인'을 누르면 체험 관리자로 들어갑니다.

## 파일

- `index.html`: 화면 전체
- `store.js`: 저장소(Firebase Firestore). `firebaseConfig`가 비어 있으면 체험 모드로만 돕니다.
- `firestore.rules`: 보안 규칙(구글 로그인 + 편집자 명단).
- `logo-scic.png`, `og.png`: 로고와 카카오톡 미리보기 그림

## 사진과 영상

- 사진은 올릴 때 브라우저에서 1600px 안쪽으로 줄여 Firestore에 바로 넣습니다. 무료 요금제(Spark)로 돌리려고 Firebase Storage는 쓰지 않습니다.
- 영상은 유튜브에 올린 뒤 주소를 붙여 넣습니다.
